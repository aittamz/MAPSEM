# MAPSEM
MAPSEM (Mapping Printed Sources of Entertainment Music in Twentieth-Century Italy) – DATA e VISUALISATION

## Interfaccia bilingue

`lingua.js` contiene le traduzioni IT/EN dell’interfaccia. Il selettore mantiene la preferenza del sito personale e i link permettono di tornare alla home. Nomi, titoli e termini trascritti dalle fonti restano nella lingua originale; le traduzioni non modificano i dati.

Per cambiare presentazione e schede dell’atlante modifica `index.html`; per aggiungere o correggere una traduzione dell’interfaccia modifica il dizionario in `lingua.js`. I dati degli editori e dei film sono rispettivamente in `editori-dati.js` e `film-dati.js`. Il corpus Sankey e i grafi mantengono i propri file originali.
